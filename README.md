# Bateu Mania Merch

Landing page merch Bateu Mania (Barisan Aneuk Teknik, Universitas Syiah Kuala): kaos, jaket, ganci, stiker, dan Paket 1–4.

Pemesanan lewat Google Form: https://forms.gle/h2Co1AUK5pVNuR8u8

## Struktur

- `index.html` — halaman utama (HTML + CSS + JS dalam satu file)
- `assets/` — logo, foto produk, dan poster

## Ubah harga atau teks

Buka `index.html`, cari nama produknya (misal `Paket 2`), lalu ubah angka di `price-num` dan `price-idr`.
